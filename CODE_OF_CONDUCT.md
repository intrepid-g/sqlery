# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcome newcomers, and do not harass anyone.

To report a problem, open a private security advisory or contact the maintainer through the GitHub profile at <https://github.com/intrepid-g>. The maintainer will review each report and keep the reporter private.
