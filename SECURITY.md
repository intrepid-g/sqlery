# Security Policy

## Report a vulnerability

Do not open a public issue for a security problem. Use GitHub's
[private vulnerability reporting](https://github.com/intrepid-g/sqlery/security/advisories/new).
Include the sqlery version, the steps to reproduce, and the impact.

The maintainer will acknowledge a report within a few days and will publish a fix and an advisory when the issue is confirmed.

## Supported versions

Only the latest release gets security fixes.

For hardening advice (for example, trusted job payloads and dashboard keys), read [docs/SECURITY.md](docs/SECURITY.md).
