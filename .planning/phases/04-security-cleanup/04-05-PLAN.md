<objective>
Implement SEC-03 — close the 11 `@csrf_exempt`-bypassed state-changing admin endpoints in `src/sqlery/django_sqlery/api_views.py`. Per RESEARCH audit, these endpoints accept POST + session-cookie auth without a CSRF token, which is the textbook CSRF risk surface. The 3 other `@csrf_exempt` decorators (in `views.py`: `internal_worker` HMAC-protected, `health_check` read-only, `trigger_view` envelope-HMAC-protected) are intentionally token-auth and stay as-is.

The CONTEXT decision was "verify + test, no new middleware unless audit finds bypassed endpoints". The audit DID find 11 — so the fix is: drop `@csrf_exempt`, add one regression test, document the intentional `views.py` exemptions in `docs/SECURITY.md` (handled in 04-06).

Plan is `autonomous: false` because dropping `@csrf_exempt` is a behavior change on 11 admin endpoints that the user's existing dashboard JS may consume — human verifies dashboard still works (or files a follow-up to update the JS).

Output: 11 decorator removals + 1 regression test file.
</objective>
