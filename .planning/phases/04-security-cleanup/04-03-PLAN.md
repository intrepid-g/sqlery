<objective>
Implement SEC-01 — the three-mode authentication middleware for the standalone FastAPI dashboard. Default-on auth in standalone mode closes the unauthenticated-admin-surface threat (26 routes incl. POST/DELETE `/api/jobs`, scheduled-task CRUD, and the `/trigger` admin endpoint added in Plan 02-08).

Three modes, resolved per CONTEXT:
- **standalone** (default; app is top-level ASGI root) — require `X-Sqlery-Key` header; reject with 401 otherwise.
- **disabled** — explicit env opt-out; pass-through; one WARNING at startup.
- **inherit** — explicit env or auto-detected mount; trust the parent app's auth.

Explicit env value always wins over auto-detect.

Output: 1 new module + middleware wiring in `app.py` + 1 unit test file.
</objective>

- 32-byte URL-safe token: `secrets.token_urlsafe(32)`.
- Constant-time compare: `hmac.compare_digest(provided.encode(), expected.encode())`. Use `request.headers.get("x-sqlery-key", "")` (Starlette headers are case-insensitive); never read `scope["headers"]` directly.
- Failure response: `JSONResponse({"detail": "unauthorized"}, status_code=401)`.

    Create `src/sqlery/fastapi_sqlery/auth.py` with:

    1. `class DashboardAuthMiddleware(BaseHTTPMiddleware)` from `starlette.middleware.base`. Constructor accepts the parent `FastAPI` instance (stored as `self._our_app`) and an `expected_key` (loaded once at install time).
    2. `async def dispatch(self, request, call_next)`:
       - If `request.url.path == "/healthz"`: return `await call_next(request)` (unconditional bypass).
       - Compute `mode = resolve_auth_mode(self._our_app, request)`.
       - If `mode == "disabled"` or `mode == "inherit"`: return `await call_next(request)`.
       - If `mode == "standalone"`: read `provided = request.headers.get("x-sqlery-key", "")`. If `not hmac.compare_digest(provided.encode(), self._expected_key.encode())`: return `JSONResponse({"detail":"unauthorized"}, status_code=401)`. Else proceed.
    3. `def resolve_auth_mode(our_app, request) -> Literal["standalone","disabled","inherit"]`:
       - Read env `SQLERY_DASHBOARD_AUTH` once (case-insensitive). If `disabled` / `inherit` / `standalone`: return it directly (explicit wins).
       - Auto-detect mount: `scope_app = request.scope.get("app")`. If `scope_app is not None and scope_app is not our_app`: return `"inherit"`. Else if `scope_app is None and request.scope.get("root_path")`: return `"inherit"`. Else `"standalone"`.
    4. `def _load_or_create_key(key_path: pathlib.Path = pathlib.Path("./.sqlery/dashboard.key")) -> str`:
       - If `os.environ.get("SQLERY_DASHBOARD_API_KEY")`: return it.
       - Elif `key_path.exists()`: return `key_path.read_text().strip()`.
       - Else: `key_path.parent.mkdir(mode=0o700, parents=True, exist_ok=True)`; `key = secrets.token_urlsafe(32)`; `old_umask = os.umask(0o077)`; try: `key_path.write_text(key)`; finally: `os.umask(old_umask)`; `os.chmod(key_path, 0o600)`; log `key` ONCE to stderr at INFO level with prefix `Generated dashboard API key (stored at ./.sqlery/dashboard.key): <key>`; return `key`.
    5. `def install(app, *, key_path=None)` — top-level helper used by `app.py`: resolves mode, loads/creates key (if standalone), logs WARNING if disabled, calls `app.add_middleware(DashboardAuthMiddleware, our_app=app, expected_key=key)`.
