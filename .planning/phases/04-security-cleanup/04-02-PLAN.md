<objective>
Implement SEC-04 (`ALLOWED_TASK_MODULES`) — an opt-in allowlist that restricts which Python module paths a worker may import when dispatching a job. Default behavior unchanged (allow all) to preserve BC across the entire existing user base. When configured, enforce a prefix-with-dot-boundary match before `importlib.import_module`. When unset in a production-shaped environment, emit a one-line WARNING nudging operators to harden.

Purpose: close the "anyone who can enqueue a job can execute arbitrary Python by passing a chosen module path" risk for users who opt in, without breaking anyone who doesn't.
Output: 1 new module + 1 wired callsite + 2 config wirings + 1 unit test file.
</objective>
