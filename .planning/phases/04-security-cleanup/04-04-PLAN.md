<objective>
Implement SEC-02 — block webhook deliveries whose destination resolves into a private, link-local, loopback, CGNAT, unspecified, or cloud-metadata IP range. Defends against (a) accidental SSRF when an operator configures a bad webhook URL and (b) malicious tenants in multi-job-source deployments using webhooks to scan internal infra or exfiltrate cloud-metadata creds.

Resolve-then-check pattern (per RESEARCH "Webhooks SSRF Integration Point"): `socket.getaddrinfo` returns ALL IP families, we check each against denylists. ~50ms DNS-rebinding window is a documented v1 limitation; pinning the resolved IP at the urllib3 level is deferred to v2.

Depends on 04-01 because the webhooks file has been moved to `src/sqlery/django_sqlery/webhooks.py`; we patch the canonical post-move location.

Output: 1 new package (`sqlery.security`) + 1 module (`ssrf.py`) + 1 wired callsite + 1 unit test file.
</objective>

Per RESEARCH pitfall: SSRF check must run BEFORE the `if requests is None: return` short-circuit, so blocked URLs still produce a WARNING + False return without making a DNS roundtrip the operator can't see.
  - Concretely: validate first → if blocked, log + return False → else, if `requests is None`, log + return False → else `requests.post(...)`.
- Concrete denylist constants per RESEARCH "Concrete denylist constants" block (copy verbatim into ssrf.py).
- `getaddrinfo` returns list of `(family, type, proto, canonname, sockaddr)`. `sockaddr` is `(ip, port)` for v4 and `(ip, port, flowinfo, scopeid)` for v6. Use `ipaddress.ip_address(sockaddr[0])` to normalize and check against the relevant `BLOCKED_V4_NETS` / `BLOCKED_V6_NETS`.
- Callsite is inside `mark_success` / `mark_failed` Django model methods — a raised exception would crash those flows. Catch `WebhookURLBlocked` inside `send_webhook` and convert to False return.

    - `def _ip_blocked(ip: ipaddress.IPv4Address | ipaddress.IPv6Address, *, allow_loopback: bool) -> bool` — checks against the relevant `BLOCKED_*_NETS`; honors `allow_loopback` to skip `127/8` and `::1`.
    - `def validate_webhook_url(url: str, *, allow_loopback: bool = False) -> None`:
      1. Parse url with `urllib.parse.urlparse`. If `scheme not in ("http", "https")`: raise `WebhookURLBlocked("scheme")`. (Blocks `file://`, `gopher://`, etc.)
      2. Lowercase hostname. If in `BLOCKED_HOSTNAMES`: raise.
      3. If hostname is a literal IP (`ipaddress.ip_address(host)` succeeds): check `_ip_blocked`; raise if blocked.
