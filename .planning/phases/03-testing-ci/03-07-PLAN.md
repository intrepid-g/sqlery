The `postgres` marker semantics agreed for this project:
- A test with ONLY `@pytest.mark.postgres` runs in the PG job, not the SQLite job.
- A test with both `@pytest.mark.postgres` and `@pytest.mark.sqlite` (or no marker) runs in both jobs — but is responsible for selecting the engine via the `db_engine` fixture.
- Default (no marker) = SQLite job only.
