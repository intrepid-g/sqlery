       ```python
       def enqueue(db_url: str, task_path: str, **kwargs):
           """Open a short-lived SQLAlchemyBackend against db_url and call the standard
           enqueue path. Returns the job_id. Disposes the engine on exit."""
           from sqlalchemy import create_engine
           from sqlmodel import SQLModel
           from sqlery.fastapi_sqlery.backend import SQLAlchemyBackend
           engine = create_engine(db_url, connect_args={"check_same_thread": False})
           SQLModel.metadata.create_all(engine)
           backend = SQLAlchemyBackend(engine=engine)
           try:
               return backend.enqueue_job(task_path=task_path, **kwargs)
           finally:
               engine.dispose()
       ```
       Document that `task_path` is the dotted path the worker will import (e.g. `tests.chaos.conftest.task_sleeps`).
