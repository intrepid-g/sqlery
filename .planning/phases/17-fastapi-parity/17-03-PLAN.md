<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| get_raw_cursor() → psycopg cursor | Raw DBAPI cursor passed to partitioning.py; caller must close both cursor and connection |
| archive_hook → operator callable | D5: archive hook runs operator-supplied Python code; trust boundary is the operator's deployment |
| staging payload → QueuedJob | Promotion reads job_spec from ScheduledJobStaging.payload; must not allow arbitrary code execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-08 | Tampering | cleanup_jobs reclaim path | mitigate | Partition reclaim destroys data beyond retention by default (D5); loud comment at routing point; SQLERY_PARTITION_ARCHIVE_HOOK opt-in documented |
| T-17-09 | Elevation of Privilege | archive_hook | mitigate | Hook receives (cur, partition_name) only; must not perform string-interpolated SQL (T-16-07 carried forward); document in get_raw_cursor docstring |
| T-17-10 | Tampering | staging payload | mitigate | payload is stored as JSON; promotion reads only known job_spec keys (allowlist pattern matching DjangoBackend promote_due_scheduled_jobs) |
| T-17-11 | Information Disclosure | get_staged_jobs | accept | Returns staging rows already readable to authenticated API callers; no new surface beyond get_job_by_id |
| T-17-12 | Denial of Service | write-path fetch-then-update | accept | Extra SELECT per write on PG adds one RTT; acceptable cost for partition pruning on terminal-status paths (not hot path) |
| T-17-SC | Tampering | pip installs | accept | No new packages; psycopg already in lockfile |

</threat_model>
