  <behavior>

    - For each in-flight job, the worker FIRST calls `await backend.amark_shutting_down(job_id)` to write the transient state, THEN races the job task against `asyncio.sleep(deadline)` via `asyncio.wait({task, deadline_timer}, return_when=FIRST_COMPLETED)`.
    - If the job finishes first (within deadline): mark `finished` with real result. The `shutting_down` write is overwritten — state is write-once at the terminal level only (transient → terminal transition).
    - If the deadline elapses: cancel the job task, mark `failed` with error message `'shutdown_timeout: worker terminated before job finished'`. If the job's `max_retries > 0`, the standard failed-with-retries path requeues it.
    - Configurable via `SQLERY_ASYNC_SHUTDOWN_DEADLINE_SECONDS` env var, default 60s [ASSUMED — surface in plan].
    - Signal handler installed via `loop.add_signal_handler` only.
  </behavior>
