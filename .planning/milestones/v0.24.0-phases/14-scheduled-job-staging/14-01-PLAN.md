<objective>
Create the ScheduledJob staging model and its migration (0029_scheduled_job_staging), which is the schema foundation for the entire phase. Far-future jobs are inserted into sqlery_scheduled_job instead of sqlery_queued_job so they cannot pin partitions. The id column shares the sqlery_queued_job_id_seq sequence to guarantee globally unique ids across both tables.

Purpose: Partition-bloat invariant — a row in sqlery_scheduled_job can never pin a partition because it is not in the partitioned table.
Output: ScheduledJob model in models.py, migration file 0029_scheduled_job_staging.py depending on 0028.
</objective>
