<objective>
Replace the full composite index at `src/sqlery/django_sqlery/models.py:592` with a partial
index covering only rows where `status='queued'`. This eliminates index bloat from finished
rows on the hottest table in the system. The hot claim path already orders by
`(-priority, created_at)` (backend.py:870-874), so the partial index matches exactly.

Purpose: The full index grows with every finished job; the partial index stays bounded by the
number of pending jobs regardless of total throughput.

Output: Updated `models.py` Meta.indexes + new migration `0028_partial_pending_index.py` using
concurrent operations to avoid a write lock on the live jobs table.
</objective>
