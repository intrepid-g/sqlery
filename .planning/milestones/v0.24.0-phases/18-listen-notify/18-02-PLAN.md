<objective>
Implement the pg_notify enqueue hook for both Django and SQLAlchemy backends, gated
behind SQLERY_PG_NOTIFY and only on PostgreSQL.

Purpose: After a job is inserted into the queue (both the main sqlery_queued_job path
and the staging sqlery_scheduled_job path are excluded — staging jobs are not yet
ready to dispatch), call pg_notify('sqlery_job_<queue>', '') so LISTEN-enabled workers
can wake immediately. The notify fires after the transaction commits (Django uses
on_commit; SQLAlchemy fires after session.commit()). When flag off or SQLite:
byte-identical — no extra connection, no extra call.

Output: New file src/sqlery/core/pg_notify.py (channel sanitizer + two thin notify
helpers). Two modified backends (create_job only).

Define sanitize_queue_name_to_channel(queue_name: str) -> str:
  - Raise ValueError("queue_name must be non-empty") if queue_name is falsy after strip.
  - Replace any character NOT in [a-zA-Z0-9_] with underscore using re.sub(r'[^a-zA-Z0-9_]', '_', queue_name).
  - Prepend "sqlery_job_" prefix.
  - Truncate the full channel string to 63 characters (PostgreSQL identifier limit) if longer.
  - Return the channel string. Security: the prefix + re.sub guarantee the channel is
    composed only of alphanumeric chars and underscores — no injection risk even when
    passed to pg_notify via a parameterized query.

Define notify_queue_django(queue_name: str) -> None:
  Docstring: "Emit pg_notify after Django transaction commits. No-op on SQLite or non-PG."
  - Guard: check that Django is available AND the active connection is PostgreSQL.
    Use: try to import django.db.connection; if vendor != 'postgresql': return.
  - Compute channel = sanitize_queue_name_to_channel(queue_name).
  - Schedule via transaction.on_commit(lambda: _fire_django_notify(channel)).
    _fire_django_notify(channel) opens a fresh cursor and executes
    "SELECT pg_notify(%s, '')" with [channel] as the parameter. Wrap in try/except
    Exception, logging a warning on failure (never crash enqueue on notify error).
  - Import transaction from django.db at module level in a try/except block;
    set _django_transaction = None if Django is not installed.

Define notify_queue_sqlalchemy(queue_name: str, session) -> None:
  Docstring: "Emit pg_notify after SQLAlchemy session.commit(). No-op on SQLite."
  - Guard: check session.get_bind().dialect.name (or session.bind.dialect.name for
    compatibility) == 'postgresql'; if not, return. Use a try/except around the
    dialect check so a missing bind never crashes enqueue.
  - Compute channel = sanitize_queue_name_to_channel(queue_name).
  - Execute session.execute(text("SELECT pg_notify(:ch, '')"), {"ch": channel}).
    This runs in the same transaction as the job INSERT and fires on commit.
    Import text from sqlalchemy at module level in a try/except; set _sa_text = None
    if SQLAlchemy is not installed. If _sa_text is None, return.
  - Wrap in try/except Exception, logging a warning on failure.

Export: __all__ = ["sanitize_queue_name_to_channel", "notify_queue_django",
