    _list_partitions(cur, table: str) -> list[tuple[str, datetime | None]]:
    - Query: SELECT c.relname, pg_get_expr(c.relpartbound, c.oid)
             FROM pg_inherits i JOIN pg_class c ON c.oid = i.inhrelid
             WHERE i.inhparent = %s::regclass
    - For each row: parse the TO ('...') timestamp from the expression using a regex.
      Return None for DEFAULT (expression contains 'DEFAULT' or regex yields no match).
    - Return list of (partition_name: str, upper_bound: datetime | None).

    ensure_future_partitions(cur, table: str, interval_str: str, premake: int) -> int:
    - First: SELECT pg_try_advisory_lock(ADVISORY_LOCK_ENSURE). If False, return 0 immediately.
    - For i in range(premake + 1):
        lo = date_trunc('day', now()) + (i * interval::interval)  — computed in Python
        via: cur.execute("SELECT date_trunc('day', now()) + (%s * %s::interval)", [i, interval_str])
        hi = lo + interval
        name = "sqlery_queued_job_" + lo.strftime("%Y%m%d")  (daily granularity, D1)
      - Execute CREATE TABLE IF NOT EXISTS {name} PARTITION OF {table}
          FOR VALUES FROM (%s) TO (%s)  — using Identifier for name and table
      - Catch psycopg.errors.InvalidTableDefinition (or CheckViolation?) for
        the attach-conflict error (rows in DEFAULT overlap the new range).
        On catch: log a WARNING f"Partition attach conflict for {name}: {e} — rows in DEFAULT partition, manual cleanup required"; continue loop — do NOT re-raise.
    - Release advisory lock: SELECT pg_advisory_unlock(ADVISORY_LOCK_ENSURE)
    - Return count of partitions actually created.

    reclaim_drained_partitions(cur, table: str, retention_str: str, archive_hook=None) -> int:
    - First: SELECT pg_try_advisory_lock(ADVISORY_LOCK_RECLAIM). If False, return 0 immediately.
    - Call _list_partitions(cur, table).
    - For each (name, upper_bound):
        Skip 1: upper_bound is None → skip (DEFAULT partition, per R4 + pgwq reference)
        Skip 2: upper_bound > now(UTC) - retention → skip (inside retention window)
        Skip 3: execute "SELECT EXISTS(SELECT 1 FROM {name} WHERE status IN ('queued','running'))"
                using Identifier for name. If True → skip (back-pressure invariant, R4)
        Action:
          a. DETACH PARTITION: ALTER TABLE {table} DETACH PARTITION {name}
             (shrinks lock window — constraints.md operational requirement)
          b. If archive_hook is not None: call archive_hook(cur, name) — catches any
             exception, logs ERROR, continues to DROP (do not block reclaim on hook failure)
          c. DROP TABLE {name}
    - Release advisory lock: SELECT pg_advisory_unlock(ADVISORY_LOCK_RECLAIM)
    - Return count of dropped partitions.

    check_default_partition(cur, table: str) -> int:
    - Derive default partition name: query pg_inherits + pg_get_expr for rows where
      expression contains 'DEFAULT', get relname.
    - If none found, return 0.
    - Execute SELECT COUNT(*) FROM {default_name} using Identifier.
    - Return the integer count. Log WARNING if count > 0:
      f"DEFAULT partition {default_name} holds {count} rows — these are never reclaimed; manual re-insert or archive required"

    All SQL identifier interpolation uses psycopg.sql.Identifier (never f-string for
    table/partition names). Literal values use %s parameterization.
    Cyclomatic complexity per function ≤ 10.
