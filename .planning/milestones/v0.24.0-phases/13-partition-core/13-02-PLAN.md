<objective>
Wire the partition maintenance machinery into the two existing framework-agnostic modules:

1. src/sqlery/core/cleanup.py — add a routing seam so that when the backend signals
   partitioned_pg=True, auto_cleanup defers to partition maintenance instead of the
   batched-DELETE path. The backend._partitioned_pg() helper is fully wired in Phase 16;
   this plan adds the ROUTING SEAM only — the if-branch, the call, and the stub guard.

2. src/sqlery/core/daemon.py — add PARTITION_MAINTENANCE_INTERVAL_MINUTES config key
   (default 5), add config validation that this value ≤ SQLERY_PARTITION_INTERVAL, and
   run ensure_future_partitions + reclaim_drained_partitions + check_default_partition on
   that cadence inside the existing _run_daemon tick loop. Every maintenance call is
   wrapped in try/except so a maintenance failure never crashes the daemon loop (per the
   existing pattern for scheduler, zombie-cleanup, etc.).

Purpose: Complete the daemon wiring for Phase 13. The actual partition DDL is in
partitioning.py (Plan 01). This plan connects that module to the daemon tick.

Output: Modified cleanup.py and daemon.py — both edits follow the comment-out-then-add
convention (never delete lines outright, per project conventions).
</objective>

           """Return True if enough time has passed since last partition maintenance run."""
           if last_run is None:
               return True
           elapsed = (datetime.now(timezone.utc) - last_run).total_seconds()
           return elapsed >= interval_minutes * 60

    3. Add config validation helper (module level, after _should_run_partition_maintenance):

       def _validate_partition_maintenance_interval(interval_minutes: int, partition_interval_str: str) -> None:
           """Raise ValueError if maintenance interval exceeds partition interval.

           Per D1/constraints.md: PARTITION_MAINTENANCE_INTERVAL_MINUTES must be ≤
           SQLERY_PARTITION_INTERVAL to ensure partitions are provisioned ahead of time.
           """
           import re as _re
           m = _re.match(r'(\d+)\s*(day|hour|minute)', partition_interval_str, _re.IGNORECASE)
           if m is None:
               return  # Unknown format — skip validation (fail safe)
           count, unit = int(m.group(1)), m.group(2).lower()
           partition_minutes = count * {'day': 1440, 'hour': 60, 'minute': 1}[unit]
           if interval_minutes > partition_minutes:
               raise ValueError(
                   f"PARTITION_MAINTENANCE_INTERVAL_MINUTES={interval_minutes} exceeds "
                   f"SQLERY_PARTITION_INTERVAL={partition_interval_str} "
                   f"({partition_minutes} min). Partitions would not be provisioned ahead of time."
               )

       NOTE: The re import here is inside the function (inline import), which is an
       exception allowed for one-time startup validation (avoids adding 're' to the module
       imports if not already present; check existing imports first — if 're' is already
