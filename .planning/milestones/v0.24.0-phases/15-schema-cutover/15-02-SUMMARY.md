### 0030_partition_queued_job.py

Single file created with:

**Part A — _VendorGuardedCutover (RunPython subclass):**

9 idempotent SQL statements executed only when `connection.vendor == "postgresql"`:

1. **S1** — `DO $$ IF to_regclass('public.sqlery_queued_job_legacy') IS NULL AND ... ALTER TABLE ... RENAME` — guarded rename of live table to `_legacy`
2. **S2** — `CREATE TABLE IF NOT EXISTS sqlery_queued_job (LIKE sqlery_queued_job_legacy INCLUDING DEFAULTS INCLUDING STORAGE) PARTITION BY RANGE (created_at)` — NOT INCLUDING IDENTITY (senior finding #1)
3. **S3** — Catalog-guarded `ADD PRIMARY KEY (created_at, id)` (checks `pg_constraint` before executing)
4. **S4** — Catalog-guarded `ADD GENERATED BY DEFAULT AS IDENTITY` on id (checks `pg_attribute.attidentity`)
5. **S5** — `CREATE TABLE IF NOT EXISTS sqlery_queued_job_default PARTITION OF sqlery_queued_job DEFAULT`
6. **S6** — `CREATE INDEX IF NOT EXISTS sqlery_job_pending_idx ON sqlery_queued_job (queue_name, priority DESC, created_at) WHERE status = 'queued'` — byte-identical to 0028 (D7)
7. **S7** — Python loop over `date_trunc('day', MIN(created_at))` through `now()+PREMAKE` creating daily partitions with `CREATE TABLE IF NOT EXISTS sqlery_queued_job_YYYYMMDD PARTITION OF sqlery_queued_job FOR VALUES FROM (%s) TO (%s)` — BEFORE the bulk copy (prevents DEFAULT-partition trap, finding #2). Also handles empty-table case with forward-looking window.
8. **S8** — `INSERT INTO sqlery_queued_job SELECT * FROM sqlery_queued_job_legacy ON CONFLICT DO NOTHING` — idempotent on re-run
9. **S9** — `SELECT setval(pg_get_serial_sequence('sqlery_queued_job', 'id'), (SELECT COALESCE(MAX(id), 1) FROM sqlery_queued_job))` — seeds identity sequence past max(id)

**Rollback (_backward):**
- `CREATE TABLE IF NOT EXISTS sqlery_queued_job_unpartitioned (LIKE sqlery_queued_job INCLUDING DEFAULTS INCLUDING STORAGE)`
- `INSERT INTO sqlery_queued_job_unpartitioned SELECT * FROM sqlery_queued_job ON CONFLICT DO NOTHING`
- Guarded rename of partitioned table to `_partitioned_bak`
- Rename `_legacy` back to `sqlery_queued_job`

Legacy table is NOT dropped — deferred per D3.
