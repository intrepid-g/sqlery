<objective>
Prove PARITY-02 (no-duplicate firing under two-leader overlap) and PARITY-03 (drift-free
`next_run_at` advance across several ticks) on the **Postgres** half of the matrix for BOTH
integration modes — closing the gap left by Phase 10, which proved these behaviors only on
SQLite and explicitly deferred the `{Django, standalone} × Postgres` cells to Phase 11.

The behaviors under test already shipped in Phase 10 (the atomic CAS
`advance_scheduled_task_if_due` and the hardened `sqlery.core.scheduler.Scheduler` firing path).
This plan adds the missing Postgres cells only — no production source changes.

Purpose: Make the no-duplicate and drift guarantees first-class CI-gated proofs across the full
database axis for both integrations, so PARITY-05's matrix gate (Plan 03) has real PG cells to run.
Output: New `@pytest.mark.postgres` test classes/methods in `tests/test_atomic_scheduler.py`
(Django×Postgres) and `tests/test_core_standalone.py` (standalone×Postgres), each asserting the
identical single-fire / drift-free invariant the existing SQLite cells assert.
</objective>
